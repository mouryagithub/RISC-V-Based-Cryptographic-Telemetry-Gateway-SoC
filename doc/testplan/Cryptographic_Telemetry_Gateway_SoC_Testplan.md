## 1. Testplan Overview

This document defines the comprehensive verification testplan for the **RISC-V Based Cryptographic Telemetry Gateway SoC with AES-256 and SHA-256 Engines**. The testplan covers all integrated subsystems across 8 functional groups, spanning 38 detailed test cases.

Each test case specifies:
1. **Testname & Objectives:** Unique identifier and functional description.
2. **Checkpoint:** Success criteria and expected architectural state.
3. **C Verification Part:** Firmware routine running on the VeeR core or DPI-C.
4. **SV Verification Part:** SystemVerilog testbench, assertions, monitors, and scoreboards.
5. **Internal/ External Test:** Whether the test verifies on-chip logic/registers (`Internal`) or physical boundary pin communication (`External`).
6. **External Interfaces:** Specific chip boundary pins and physical interfaces used by external tests (e.g. `uart_tx`, `gpio_o`, `Reset (aresetn)`, or `None` for internal tests).
